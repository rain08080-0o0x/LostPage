# Lost Page

4色の「エーテル」を組み合わせてカードを発動し、分岐マップの最深部を目指すターン制デッキ構築ローグライトです。

毎ターン得られるエーテルはランダムですが、その色と総数は自分のデッキに入れたカードのコストから作られます。強いカードを増やすほど行動の選択肢は広がる一方、必要な色を引ける確率も変わる――デッキ構築と戦闘中のリソース管理が一体になったゲームです。

- 対応環境：Windows 64-bit / Android 8.0以上（ARM64）
- 最新公開版：v1.2.1
- 開発ブランチ：`alpha`
- 開発環境：Unity 6000.3.12f1
- 企画・現行仕様：[LostPage企画草案.md](./LostPage企画草案.md)

## 起動方法

### Windows

1. `LostPage-v1.2.1-Windows.zip`をダウンロードします。
2. ZIPを右クリックし、「すべて展開」などで任意のフォルダへ展開します。
3. 展開先にある`LostPage.exe`を起動します。

`LostPage.exe`だけを別の場所へ移動せず、`LostPage_Data`や`UnityPlayer.dll`と同じ構成のまま起動してください。インストーラーや追加データのダウンロードは不要です。

### Android

1. `LostPage-v1.2.1-Android.apk`を端末へダウンロードします。
2. Androidの案内に従い、使用したブラウザまたはファイル管理アプリに「不明なアプリのインストール」を一時的に許可します。
3. APKを開いてインストールします。
4. アプリ一覧から「Lost Page」を起動し、横画面でプレイします。

APK以外の追加ファイルは不要です。v1.2.1のAPKはGitHub配布用のデバッグ証明書で署名されており、Google Play向けの正式署名版ではありません。

## このゲームの面白さ

### デッキが「引ける資源」まで変える

カードのエーテルコストを合計したものが、その戦闘で使うエーテルプールになります。赤を多く使う攻撃カードを増やせば赤を引きやすくなりますが、プール全体も大きくなります。カードを1枚取るたびに、効果だけでなく次の戦闘の色配分まで変化します。

### 使い切るか、次へ残すか

通常は毎ターン5個のエーテルを取得し、残ったものを基本2個まで次のターンへ持ち越せます。今すぐ小さく動くか、必要な色を保存して次のターンに大技を狙うかを選びます。

### 使用順で結果が変わる

チャージ、弱体、攻撃力、防御力、貫通、防御維持、自動防御、持続効果、クールタイムが組み合わさります。どのカードを先に使い、どの効果を次の一手へ渡すかが重要です。

### 一本道ではない攻略

マップは奥へ進むほど1、2、3、4……と横に広がり、戦闘、回復の泉、ショップ、報酬の間、道具の間、ランダムイベント、ボスを選びながら進みます。前後だけでなく、同じ行で左右に隣接するマスへも移動でき、訪れた道を戻ることもできます。ただし、移動するたびに下から霧が1行迫り、霧の中へ入るとHPが減ります。ショップには何度でも入れるものの、霧に覆われた経路を通る場合はダメージを受けます。

## 初めて遊ぶとき

1. ゲーム開始時、ランダムに提示される通常道具3個から1個を選びます。
2. 分岐マップで、霧の境界を確認しながら現在地と線でつながっているステージへ進みます。
3. 最初の戦闘では操作ガイドを開始するか、今回はスキップするかを選べます。
4. 手番エーテルで支払えるカードを選び、敵または中央のカード詳細欄へドラッグして使用します。
5. 行動を終えるときは、エーテルがなくても自動終了を待たず「ターン終了」を押します。
6. 持ち越し上限より多くエーテルが残っていれば、次のターンへ残すエーテルを選びます。選択画面はキャンセルできます。
7. 敵を全滅させると、敵1体につき10～15ゴールドと、3択から選ぶカード1枚を獲得します。各候補は通常75%・レア25%で抽選されます。
8. ボスを倒すと通常の敵報酬に加えて100～150ゴールドを獲得し、最大HPが10増えて全回復します。最終層以外ではボスカード、ボス道具を順に1つずつ選べます。
9. 全5層を攻略するとランクリアです。

## ゲームシステム概要

### 初期状態

- HP：100
- 初期ゴールド：0G
- 初期デッキ：攻撃カード3枚、防御カード3枚、チャージカード1枚
- デッキ上限：なし
- 持ち越し上限：2個。鞄系道具で増加
- ターン取得数：5個。エネルギーコアで6個

### カード

実装済みカードは全55種です。

- 攻撃：既存7種に加え、切り札、成長する刀、炎撃、薙ぎ炎撃、湧き上がる炎、燃焼、爆炎、防御変換、熱射病
- 防御：既存5種に加え、全力防御、棘付き盾、茨の鎧、重厚鎧、カウンタードロー、フルライト自動防御、回帰防御、防壁、金貨変換
- チャージ：既存4種に加え、共鳴-青-、共鳴-黄-、共鳴-紫-、貫通力、攻撃回収、赤紙召喚、揺らぐ影、マジックミラー、複製攻撃
- 持続：既存2種に加え、防御持続、赤い紅い月、貫盾、追加防御、防御補助、二回攻撃、全体攻撃、リストサポーター、焼入れ
- 特殊：神撃

カード取得時のデッキは攻撃、防御、チャージ、持続、特殊の順で整理されます。戦闘画面では同じ5分類と全表示で絞り込み、「使用可能優先・種類別・入手順」で並び順を切り替えられます。フィルターと並び順は同じ戦闘中のカード使用やターン更新後も維持され、別のステージへ移動すると全表示・使用可能優先へ戻ります。標準の使用可能優先では使えるカードを左、使えないカードをグレー表示で右へ寄せます。同名カードもそれぞれ個別に表示・管理されます。持続カードだけは同じ種類を複数所持できません。

通常・レア・ボス・特殊の4レア度があります。神撃以外のカード個体は1回だけ強化でき、強化後は効果、コスト、CTのいずれかが変化します。マップ画面の「所持カード」から、分類タブごとにレア度・強化状態・効果・コスト・CTを確認できます。

各カードのコスト、効果、クールタイムは[企画・現行仕様書のカード一覧](./LostPage企画草案.md#8-カード一覧)を参照してください。

### マップと報酬

| ステージ | 内容 |
| --- | --- |
| 戦闘 | 敵1体につき10～15G。通常75%・レア25%で抽選された3枚から1枚を取得 |
| 回復の泉 | HPを30回復。初回のみ |
| ショップ | 分類ごとに通常3枚・レア2枚を固定陳列。初回20Gで購入ごとに5G上昇。各分類1枚までカード強化も可能 |
| 何もない場所 | 既存3種とカード強化2種から、成立するイベントを等確率で1つ抽選 |
| 報酬の間 | ランダムなカード2枚を自動取得。30%で未所持のレア道具も獲得 |
| 道具の間 | 各層に1マス。通常道具3択から1個を取得 |
| ボス | 追加100～150G。層クリア、最大HP+10・全回復。最終層以外はボスカード3択の後にボス道具3択 |

マップの奥行きは1～5層で4～8行のまま、各行が1、2、3……マスへ広がります。各マスは前後の行に加えて、同じ行の左右に隣接するマスとも接続されます。何もない場所は層ごとに2～3、4～5、7～9、11～13、15～17マス配置され、イベント系マスの総数が戦闘マスより多くなります。

霧は各層の開始地点を深度0として、深度-5から始まります。マスを1回移動するごとに1行進み、移動先が霧の境界以下ならシールドを無視してHPへ直接ダメージを受けます。ダメージは1～5層で5、7、9、11、13です。次の層へ進むと霧は深度-5へ戻ります。

通常敵は層に応じて1～3体出現し、HP倍率は100%、150%、250%、400%、700%（1体400上限）です。ボスHPは120、240、480、800、1200で、敵攻撃力は3層・5層で少しだけ上昇します。

### 持ち込み道具

道具は通常7種、レア4種、ボス6種に、条件入手の特殊道具「明星」を加えた全18種です。

- 開始時：通常道具3択から1個
- 各層の道具の間：通常道具3択から1個
- 報酬の間：30%でレア道具1個
- 1～4層のボス：ボス道具3択から1個
- 所持上限：大きな鞄のみ2個、その他は1個

効果の詳細は[企画・現行仕様書の道具一覧](./LostPage企画草案.md#13-持ち込み道具一覧)を参照してください。

## チュートリアル

初回戦闘では、実際の操作に合わせて次の4段階を案内します。

1. 攻撃カードを敵へ使用
2. 自分でターンを終了
3. 次のターンへ持ち越すエーテルを選択
4. チャージカードを中央の詳細欄へ使用

ガイドは途中でスキップできます。また、マップ画面と戦闘画面の「遊び方」から、次の5ページをいつでも確認できます。

1. 戦闘画面とエーテル
2. 攻撃と敵の選択
3. 自分に使うカード
4. ターン終了と持ち越し
5. マップ・霧とデッキ強化

ページは前後ボタンまたは横スワイプで切り替えられます。

## Unityで開発・ビルドする

1. Unity HubへUnity 6000.3.12f1を追加します。
2. このリポジトリのルートフォルダをUnityプロジェクトとして開きます。
3. 必要に応じて`Lost Page > Setup Project`を実行します。
4. `Lost Page > Validate Model`でモデル仕様を検証します。
5. 対象環境に応じて次を実行します。

| メニュー | 出力先 |
| --- | --- |
| `Lost Page > Build Windows` | `Builds/Windows/LostPage.exe` |
| `Lost Page > Build Android` | `Builds/Android/LostPage.apk` |

AndroidビルドにはUnity HubからAndroid Build Support、SDK、NDK、OpenJDKを追加する必要があります。
