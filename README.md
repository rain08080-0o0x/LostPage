# Lost Page

エーテルを組み合わせてカードを使い、分岐マップを攻略するデッキ構築型ローグライトです。

AndroidとWindowsに対応しています。

## ダウンロード

[Releases](https://github.com/rain08080-0o0x/LostPage/releases)から最新版をダウンロードできます。

- Android：`LostPage-v1.1.1-Android.apk`
- Windows：`LostPage-v1.1.1-Windows.zip`

Windows版はZIPを展開し、`LostPage.exe`を起動してください。Android版はAPKを端末へインストールしてください。

## ゲーム概要

- 赤・青・黄・紫のエーテルを消費してカードを発動
- 攻撃、防御、チャージ、持続カードによるデッキ構築
- 戦闘、泉、ショップ、報酬、ランダムイベント、ボスで構成される分岐マップ
- 階層の進行に応じて増加するステージ数と敵HP
- カード報酬、持ち込み道具、バフ・デバフ、クールタイム
- 一度訪れたマスへの再移動とマップ全体の確認

## 操作

- カードをタップ：カード詳細を表示
- カードを敵へドラッグ：対象へカードを使用
- カードを上方向へドラッグ：チャージ・持続などを発動
- カード列を横へスワイプ：カード一覧をスクロール
- 「選択中の敵へ使用」ボタンからもカードを使用可能
- 「遊び方」からチュートリアルを再確認可能

## 動作環境

- Android：Android 8.0（API 26）以上、ARM64
- Windows：64-bit Windows

## 開発環境

- Unity 6000.3.12f1
- uGUI 2.0.0
- IL2CPP（Android）

Unityでプロジェクトを開き、次のメニューからビルドできます。

- `Lost Page > Build Windows`
- `Lost Page > Build Android`
